## 估值表使用说明（螺丝钉原文注释）

1. **盈利收益率法**：盈利收益率大于 10% 可以投资。
2. **市盈率法**：盈利增速比较快的品种，适合参考市盈率、市净率辅助参考。在估值处于底部的时候适合投资。
3. **市净率法**：强周期性行业品种，盈利波动大，跟盈利相关的指标都不适合参考。适合参考市净率，在市净率处于低估的时候可以投资。波动大不适合重仓，单个品种控制在总资产 10% 以下。
4. **投资星级**：1 星为泡沫阶段，5 星为投资价值最高阶段。

## 关键设计启示

1. **估值表按品种盈利特征分区**（盈利稳定/盈利快速/强周期/海外/债券），不同板块采用不同估值方法——这决定了程序的数据结构：每个指数需标注 `method` 字段（EP=盈利收益率 / PE=市盈率 / PB=市净率）。
2. 每日更新，日期为前一交易日。
3. 同时给出场内/场外基金代码，便于直接操作。
4. 星级独立于具体指数，是整体市场估值指标（1星泡沫~5星价值最高）。
5. 用户 11 个标的在螺丝钉表中对应板块：
   - 上证红利→盈利收益率法板块；红利机会→市盈率法；50AH优选→盈利收益率法；中证医疗/中证白酒/生物科技→PE板块（表中未见，需扩展）；H股指数→盈利收益率法；科技100→PE板块（表中37.61）；消费50→PE板块近似（可选消费18.95）；基本面60→PE板块（22.71）。
